# StoneHub

StoneHub is an online marketplace for Demkyembo Marble and Granite Company Ltd. It enables customers to browse, search, and order marble and granite products while allowing administrators to manage products, inventory, and customer orders.

## Features

- Customer registration and login
- Browse products by category
- View product details
- Shopping cart
- Place orders
- Order tracking
- Admin dashboard
- Product and inventory management

## Technologies

- JavaScript
- Node js
- MySQL
- HTML/CSS
- React
- Git & GitHub
